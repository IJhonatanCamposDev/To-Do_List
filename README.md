# 📝 To-Do List Avançada | JavaScript

Aplicação de lista de tarefas desenvolvida com **HTML, CSS e JavaScript puro**, com foco em organização, experiência do usuário e persistência de dados.

Projeto criado para portfólio front-end, demonstrando boas práticas de manipulação do DOM, controle de estado e uso de `localStorage`.

---

## 🚀 Funcionalidades

- ✅ Adicionar novas tarefas
- ✏️ Marcar tarefas como concluídas
- ❌ Remover tarefas
- 🔍 Filtro de tarefas:
  - Todas
  - Ativas
  - Concluídas
- 🔢 Contador de tarefas pendentes
- 💾 Persistência de dados com `localStorage`
- ✨ Animações suaves para melhor UX
- 🌙 Interface em dark mode
- 📱 Layout responsivo

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (estrutura semântica)
- **CSS3**
  - Flexbox
  - Variáveis CSS
  - Animações
- **JavaScript**
  - Manipulação do DOM
  - Eventos
  - Estado da aplicação
  - `localStorage`

---

## 🧠 Conceitos Aplicados

- Separação de responsabilidades
- Renderização dinâmica
- Controle de estado no front-end
- Persistência de dados no navegador
- Boas práticas de organização de código
